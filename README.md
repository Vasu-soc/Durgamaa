# Durgamaa

Cinematic devotional 60 FPS particle animation of Goddess Durga Maa seated on a lion, surrounded by a circular wall of flames.

## Features
- **WebGL Multi-Pass Particle Engine**: 62,000 particles with additive fire blending, alpha silhouette occlusion, and golden rim highlights.
- **Harmonic Audio Synthesizer**: Web Audio API ambient devotional drone tuned to sacred frequencies.
- **Cinematic Responsive Stage**: 9:16 mobile-first aspect ratio with volumetric radial aura and floating embers.
- **Pure Icon Interface**: Minimalist auto-hiding top controls (Replay, Aura, Audio, Fullscreen).

## Local Development
```bash
# Start local development server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
